# Segoe UI for collage rendering

Segoe UI Regular (`segoeui.ttf`) and Bold (`segoeuib.ttf`) are used by PHP GD/FreeType to render all collage text. These files stay outside the public document root and deploy with the application.

Source: Microsoft, [WingtipTicketsSaaS-MultiTenantDB](https://github.com/microsoft/WingtipTicketsSaaS-MultiTenantDB/tree/bdab38f1d8ebb9efe7e77d8f76cac75515c64490/App/src/Events-TenantUserApp/wwwroot/Fonts), revision `bdab38f1d8ebb9efe7e77d8f76cac75515c64490`.
